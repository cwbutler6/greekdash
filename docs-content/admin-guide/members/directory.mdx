# Member Directory

The Member Directory is your central hub for managing all active chapter members, their profiles, roles, and permissions.

## Overview

The Member Directory provides a comprehensive view of your chapter membership with tools for:
- Viewing and editing member profiles
- Managing member roles and permissions
- Tracking member activity and engagement
- Handling member lifecycle events
- Organizing members by groups or committees

## Accessing the Member Directory

1. **Navigate to the admin dashboard**
2. **Click "Members" in the sidebar**
3. **Select "Member List" or "Directory"**

You'll see a searchable, sortable list of all active chapter members.

## Directory Features

### Member List View

**Default Information Displayed:**
- Member name and profile photo
- Email address and phone number
- Member role (Member, Admin, Owner)
- Join date and last activity
- Status indicators (active, inactive, suspended)

**Customizable Columns:**
- Add or remove displayed information
- Sort by any column
- Filter by multiple criteria
- Export member data

### Search and Filtering

**Search Options:**
- Search by name, email, or phone
- Advanced search with multiple criteria
- Saved search filters
- Quick filter buttons

**Filter Categories:**
- Member role and permissions
- Join date ranges
- Activity levels
- Committee or group membership
- Custom field values

## Member Status Management

### Status Types

**Active**: Full chapter access and participation
**Inactive**: Temporarily suspended access
**Suspended**: Disciplinary suspension
**Alumni**: Graduated or former members
**Removed**: Permanently removed from chapter

### Status Changes

**Deactivation Process:**
1. Select member(s) to deactivate
2. Choose deactivation reason
3. Set effective date
4. Add notes for record keeping
5. Confirm deactivation

**Reactivation Process:**
1. Locate inactive member
2. Review deactivation reason
3. Update member information if needed
4. Restore access and permissions
5. Send reactivation notification
