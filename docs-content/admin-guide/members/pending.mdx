# Managing Pending Members

Learn how to review, approve, and manage pending member applications in your chapter.

## Overview

The Pending Members section allows you to review and manage members who have accepted invitations but are awaiting approval to join your chapter. This approval process helps maintain quality control and ensures only authorized individuals gain access to your chapter.

## Accessing Pending Members

1. **Navigate to the admin dashboard**
2. **Click "Members" in the sidebar**
3. **Select "Pending" from the submenu**

You'll see a list of all members awaiting approval with their application details.

## Reviewing Pending Applications

### Application Information

For each pending member, you can view:
- **Personal Information**: Name, email, phone number
- **Application Date**: When they completed registration
- **Invitation Details**: Who invited them and when
- **Profile Information**: Any additional details they provided
- **Verification Status**: Email and phone verification status

### Application Actions

**Approve Member**
- Grants full chapter access
- Sends welcome notification
- Adds to active member directory
- Assigns default member role

**Reject Application**
- Denies chapter access
- Sends rejection notification
- Removes from pending list
- Optionally provides rejection reason

**Request More Information**
- Sends message requesting additional details
- Keeps application in pending status
- Tracks communication history

## Approval Process

### Individual Approval

1. **Click on a pending member** to view full details
2. **Review all provided information**
3. **Check verification status**
4. **Click "Approve" or "Reject"**
5. **Add approval notes** (optional)
6. **Confirm the decision**

### Bulk Approval

For multiple approvals:

1. **Select multiple pending members** using checkboxes
2. **Click "Bulk Actions"**
3. **Choose "Approve Selected" or "Reject Selected"**
4. **Add bulk action notes** (optional)
5. **Confirm the bulk action**

## Managing Application Requirements

### Setting Requirements

Configure what information is required:
- **Basic Information**: Name, email, contact details

### Approval Criteria

Establish clear criteria for approval:
- Verification completion requirements

## Troubleshooting Common Issues

### Incomplete Applications

**Missing Information**
- Contact member for missing details
- Provide clear instructions
- Set reasonable deadlines
- Follow up as needed

**Verification Issues**
- Help members complete email verification
- Assist with phone number verification
- Resolve technical verification problems
- Provide alternative verification methods

### Communication Problems

**Members Not Responding**
- Try multiple communication channels
- Check contact information accuracy
- Set reasonable response timeframes
- Consider automatic rejection after timeout

**Technical Issues**
- Verify email delivery
- Check spam/junk folders
- Test notification systems
- Contact support for platform issues

## Best Practices

### Timely Processing

- **Regular Reviews**: Check pending applications daily

- **Clear Communication**: Provide status updates to pending members
- **Consistent Standards**: Apply approval criteria fairly and consistently

### Documentation

- **Keep Records**: Document approval decisions and reasoning

- **Maintain History**: Keep communication records
- **Review Policies**: Regularly update approval criteria

### Member Experience

- **Clear Expectations**: Communicate approval process and timeline
- **Helpful Guidance**: Provide assistance with application completion
- **Professional Communication**: Maintain respectful tone in all interactions
- **Quick Onboarding**: Facilitate smooth transition for approved members

## Approval Workflows

### Standard Workflow

1. Member accepts invitation
2. Completes registration and profile
3. Application appears in pending queue
4. Admin reviews application
5. Admin approves or rejects
6. Member receives notification
7. Approved members gain chapter access

### Enhanced Workflow

For chapters requiring additional verification:

1. Initial application submission
2. Automated verification checks
3. Manual review by designated approvers
4. Multi-level approval process
5. Final approval and access grant
6. Welcome and onboarding process
