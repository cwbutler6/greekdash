# Gallery & File Management

Organize, share, and manage your chapter's photos, documents, and files with GreekDash's comprehensive gallery and file management system.

## Gallery Management Overview

### Gallery Features
- **Photo Albums**: Organized collections of event and chapter photos
- **File Sharing**: Secure document and file sharing with members
- **Privacy Controls**: Granular permissions for content access
- **Storage Management**: Efficient storage with automatic optimization
- **Mobile Upload**: Easy photo and file uploads from mobile devices

### Content Types Supported
- **Images**: JPEG, PNG, GIF, WebP formats
- **Documents**: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX
- **Media Files**: MP4, MOV, MP3, WAV (with size limits)
- **Archives**: ZIP, RAR for bulk file sharing
- **Text Files**: TXT, CSV, JSON for data sharing

### File Permission Management

#### Permission Levels
- **View Only**: Members can see and download files
- **Upload**: Members can add files to folders
- **Edit**: Members can modify existing files
- **Manage**: Full control including deletion and permission changes
- **Admin Only**: Restricted to administrators only

#### Role-Based Access
- **Public Files**: Accessible to all chapter members
- **Officer Files**: Limited to leadership team
- **Committee Files**: Specific committee access only
- **Private Files**: Admin-only sensitive documents
- **Guest Access**: Limited access for non-members

### Version Control and File History

#### Version Management
- **Automatic Versioning**: Keep track of file changes and updates
- **Version History**: View previous versions of documents
- **Restore Previous**: Revert to earlier file versions
- **Change Tracking**: See who made changes and when
- **Comment System**: Add notes about file changes

#### File Collaboration
- **Simultaneous Access**: Multiple users can access files safely
- **Edit Notifications**: Alerts when files are being modified
- **Lock System**: Prevent conflicts during editing
- **Merge Capabilities**: Combine changes from multiple editors

## Troubleshooting Common Issues

### Upload Problems
- **File Size Limits**: Check file size against plan limits
- **Format Support**: Verify file format is supported
- **Network Issues**: Ensure stable internet connection
- **Browser Compatibility**: Try different browsers if issues persist
- **Storage Space**: Check available storage capacity

### Access Issues
- **Permission Problems**: Verify member has appropriate access
- **Login Issues**: Ensure member is properly authenticated
- **Mobile Problems**: Check mobile app version and updates
- **Browser Cache**: Clear cache and cookies if needed
- **Network Restrictions**: Check for firewall or network blocks

### Performance Issues
- **Slow Loading**: Optimize images and check connection speed
- **Large Files**: Consider compressing or splitting large files
- **Browser Performance**: Update browser or try alternatives
- **Mobile Performance**: Check device storage and memory
- **Server Load**: Contact support if widespread issues occur
