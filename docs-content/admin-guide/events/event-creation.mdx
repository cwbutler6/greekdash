## Event Types and Categories

### Chapter Meetings
- **Regular meetings**: Weekly or monthly chapter meetings
- **Executive meetings**: Leadership and officer meetings
- **Committee meetings**: Specific committee gatherings

### Social Events
- **Mixers**: Social gatherings with other organizations
- **Formals**: Formal dinner and dance events
- **Casual socials**: Informal member gatherings

### Service Events
- **Community service**: Volunteer opportunities and service projects
- **Fundraisers**: Charity events and fundraising activities
- **Philanthropy**: Philanthropic events and campaigns

### Educational Events
- **Workshops**: Skill-building and educational sessions
- **Guest speakers**: Professional development presentations
- **Study sessions**: Academic support and study groups

## Event Information Fields

### Required Information
- **Event Title**: Clear, descriptive name for the event
- **Date and Time**: Start and end times with timezone
- **Location**: Venue name, address, and directions
- **Description**: Detailed event information and expectations

### Optional Information
- **Event Image**: Visual representation or promotional image
- **Dress Code**: Attire requirements and guidelines
- **Cost**: Event fees or contribution requirements
- **Contact Person**: Point person for questions and coordination

### RSVP Configuration
- **RSVP Required**: Whether members must RSVP to attend
- **Capacity Limit**: Maximum number of attendees
- **RSVP Deadline**: Last date/time for responses
- **Waitlist**: Enable waitlist when capacity is reached
- **Guest Policy**: Whether members can bring guests

## Managing Existing Events

3. Click the edit icon or event title
4. Make necessary changes

### Event Status Management
- **Draft**: Event is being prepared but not visible to members
- **Published**: Event is live and visible to eligible members
- **Cancelled**: Event has been cancelled with notifications sent
- **Completed**: Event has occurred and is archived

### Bulk Operations
- **Duplicate Events**: Copy event details for recurring events
- **Bulk Notifications**: Send messages to multiple event attendees
- **Export Data**: Download attendee lists and event reports

## Event Communication

### Automatic Notifications
GreekDash automatically sends notifications for:
- Event creation announcements
- RSVP confirmations
- Event reminders (24 hours and 2 hours before)
- Event updates and changes
- Post-event follow-ups

### Custom Communications
Send targeted messages to:
- All eligible members
- RSVP'd attendees only
- Non-respondents
- Waitlisted members
- Specific member roles

## Event Analytics and Reporting

### Key Metrics
- **RSVP Rate**: Percentage of eligible members who responded
- **Attendance Rate**: Actual attendance vs. RSVP confirmations
- **Engagement Score**: Overall member engagement with event
- **Communication Effectiveness**: Open and response rates

### Reports Available
- **Event Summary**: Overview of event performance
- **Attendee List**: Complete list of participants
- **RSVP Timeline**: Response patterns over time
- **Communication Analytics**: Message delivery and engagement

## Best Practices

### Event Planning
- **Lead Time**: Create events at least 2 weeks in advance
- **Clear Expectations**: Provide detailed information about what to expect
- **Accessibility**: Consider member accessibility needs and accommodations
- **Weather Contingency**: Have backup plans for outdoor events

### RSVP Management
- **Reasonable Deadlines**: Set RSVP deadlines that allow proper planning
- **Waitlist Strategy**: Use waitlists for popular events to gauge interest
- **Follow-up**: Send reminders to non-respondents
- **Flexibility**: Allow RSVP changes within reason

### Communication Strategy
- **Multi-channel**: Use email, SMS, and in-app notifications
- **Timing**: Send announcements during optimal engagement hours
- **Personalization**: Tailor messages to different member segments
- **Consistency**: Maintain consistent communication style and branding

## Troubleshooting Common Issues

### Low RSVP Rates
- **Check timing**: Ensure events aren't scheduled during busy periods
- **Improve descriptions**: Make event details more compelling
- **Adjust communication**: Try different messaging approaches
- **Survey members**: Ask for feedback on event preferences

### Capacity Management
- **Monitor trends**: Track typical attendance vs. RSVP ratios
- **Adjust limits**: Set capacity based on historical data
- **Waitlist management**: Actively manage waitlists and communicate status
- **Venue flexibility**: Have backup venue options for popular events

### Technical Issues
- **RSVP problems**: Check member permissions and notification settings
- **Display issues**: Verify event visibility settings and member roles
- **Notification failures**: Review communication preferences and contact information
- **Data sync**: Ensure event information is properly synchronized
