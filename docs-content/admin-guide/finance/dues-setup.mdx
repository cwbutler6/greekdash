# Dues Setup and Payment Processing

Setting up dues collection is essential for maintaining your chapter's financial health. GreekDash provides comprehensive tools to create flexible dues plans, process payments securely, and track member payment status.

## Overview

**What You'll Learn:**
- How to create and configure dues plans
- Setting up payment processing with Stripe
- Managing member payment assignments
- Tracking payment status and handling overdue payments
- Automating payment reminders and late fees

**Prerequisites:**
- Chapter setup completed
- Stripe account connected (for payment processing)
- Basic financial management permissions

## Creating Dues Plans

### Step 1: Access Dues Management

1. **Navigate to Finance Dashboard**
   - Go to your admin dashboard
   - Click "Finance" in the sidebar
   - Select "Dues" tab or visit `/admin/finance/dues`

2. **Create New Dues Plan**
   - Click "New Dues Plan" button
   - The dues plan creation dialog will open

### Step 2: Configure Dues Plan Details

**Basic Information:**
- **Plan Name**: Choose a descriptive name (e.g., "Fall 2024 Semester Dues")
- **Description**: Add details about what the dues cover
- **Amount**: Set the total dues amount per member
- **Frequency**: Choose payment schedule:
  - One-time payment
  - Monthly installments
  - Semester payments
  - Annual payments

**Payment Options:**
- **Due Date**: Set when payments are due
- **Late Fee**: Configure automatic late fees (optional)
- **Grace Period**: Allow time before late fees apply
- **Payment Methods**: Enable credit cards, ACH transfers, or both

### Step 3: Advanced Configuration

**Eligibility Settings:**
- **Member Types**: Specify which member roles can be assigned
- **Status Requirements**: Set member status requirements
- **Custom Criteria**: Add specific eligibility rules

**Payment Processing:**
- **Auto-Assignment**: Automatically assign to new members
- **Proration**: Handle mid-period member additions
- **Refund Policy**: Set refund rules and procedures

## Assigning Dues to Members

### Individual Assignment

1. **Select Members**
   - Go to the "Plan Assignments" tab
   - Click "Assign Dues to Members"
   - Choose individual members from the list

2. **Bulk Assignment**
   - Select multiple members using checkboxes
   - Choose the appropriate dues plan
   - Set assignment effective date
   - Click "Assign Selected Members"

### Automatic Assignment Rules

**New Member Auto-Assignment:**
- Enable automatic assignment for new members
- Set default dues plan for new joiners
- Configure proration for mid-period additions

**Role-Based Assignment:**
- Assign different plans based on member roles
- Set up executive vs. general member dues
- Handle special member categories

## Payment Processing Setup

### Stripe Integration

**Initial Setup:**
1. **Connect Stripe Account**
   - Go to Chapter Settings > Billing
   - Click "Connect Stripe Account"
   - Complete Stripe onboarding process
   - Verify bank account information

2. **Configure Payment Methods**
   - Enable credit/debit cards
   - Set up ACH bank transfers (US only)
   - Configure digital wallets (Apple Pay, Google Pay)
   - Set payment method preferences

**Security Configuration:**
- Enable fraud detection
- Set up 3D Secure authentication
- Configure payment retry logic
- Set up webhook endpoints

### Payment Processing Flow

**Member Payment Process:**
1. Member receives payment notification
2. Clicks payment link in email or portal
3. Redirected to secure Stripe checkout
4. Completes payment with chosen method
5. Receives confirmation and receipt
6. Payment status updated in GreekDash

**Admin Monitoring:**
- Real-time payment notifications
- Payment status dashboard
- Failed payment alerts
- Reconciliation reports

## Troubleshooting Common Issues

### Payment Processing Problems

**Failed Payments:**

*Symptoms:*
- Payment shows as failed in dashboard
- Member reports payment didn't go through
- Stripe webhook errors in logs

*Solutions:*
1. Check payment method validity
2. Verify sufficient funds
3. Review fraud detection settings
4. Contact member for updated payment info
5. Manually retry payment if appropriate

**Duplicate Payments:**

*Symptoms:*
- Member charged twice for same dues
- Multiple payment records for single transaction
- Overpayment showing in member account

*Solutions:*
1. Identify duplicate transactions
2. Process refund for excess payment
3. Update payment records
4. Implement duplicate prevention measures

### Member Payment Issues

**Payment Not Reflecting:**

*Symptoms:*
- Member paid but status shows unpaid
- Payment processed but not recorded
- Webhook delivery failures

*Solutions:*
1. Check Stripe webhook logs
2. Manually sync payment status
3. Verify webhook endpoint configuration
4. Update payment record manually if needed

**Refund Requests:**

*Process:*
1. Review refund eligibility
2. Verify original payment
3. Process refund through Stripe
4. Update member payment records
5. Send refund confirmation
