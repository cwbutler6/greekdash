# Financial Management

GreekDash provides comprehensive financial management tools to help you collect dues, track expenses, manage budgets, and maintain financial transparency for your chapter.

## Financial Management Overview

### Core Financial Features

**Dues Collection**
- Automated recurring payments
- Flexible payment plans
- Multiple payment methods
- Payment tracking and reminders

**Expense Management**
- Expense categorization and tracking
- Receipt management
- Budget monitoring
- Approval workflows

**Financial Reporting**
- Real-time financial dashboards
- Detailed transaction reports
- Budget vs. actual analysis
- Member payment status

**Integration**
- Stripe payment processing
- Bank account connections
- Accounting software exports
- Tax reporting assistance

## Getting Started with Financial Management

### Prerequisites

Before setting up financial features:

1. **Verify your plan** includes financial management
2. **Gather necessary information**:
   - Bank account details
   - Tax identification numbers
   - Chapter financial policies
   - Existing dues structure

3. **Prepare documentation**:
   - Chapter bylaws regarding finances
   - Existing financial records
   - Member payment history (if migrating)

### Initial Setup Process

1. **Connect Payment Processing** (Stripe integration)
2. **Set Up Dues Plans** and payment schedules
3. **Configure Expense Categories** for tracking
4. **Establish Budget Parameters** for monitoring
5. **Train Financial Officers** on the system

**Plan Components:**
- Plan name and description

- Payment methods accepted
- Late fees and penalties
- Member eligibility criteria

**Payment Options:**
- One-time payments
- Installment plans
- Automatic recurring payments
- Manual payment entry

### Member Assignment

- Assign dues plans to individual members
- Bulk assignment by member groups
- Automatic assignment for new members
- Plan changes and adjustments

### Payment Tracking

- Real-time payment status dashboard

- Overdue payment notifications
- Payment reminder automation

## Expense Management

### Expense Categories

**Standard Categories:**
- Events and social activities
- Administrative expenses
- Facility costs
- Equipment and supplies
- Charitable donations
- Travel and transportation

**Custom Categories:**
- Create chapter-specific categories
- Set budget limits per category
- Assign approval requirements
- Track category spending trends

### Expense Submission Process

1. **Submit Expense Request**
   - Enter expense details
   - Upload receipts
   - Select appropriate category
   - Add description and justification

2. **Approval Workflow**
   - Automatic approval for small amounts
   - Admin approval for larger expenses
   - Multi-level approval for significant costs
   - Rejection and revision process

3. **Payment Processing**
   - Reimbursement to members
   - Direct vendor payments
   - Integration with accounting systems
   - Payment confirmation and tracking

## Troubleshooting Common Issues

### Payment Problems

**Failed Payments:**
- Insufficient funds
- Expired payment methods
- Bank restrictions
- Technical issues

**Resolution Steps:**
1. Identify failure reason
2. Contact member for resolution
3. Update payment information
4. Retry payment processing
5. Document resolution

### Reporting Issues

**Data Discrepancies:**
- Reconcile with bank statements
- Review transaction logs
- Check for duplicate entries
- Verify category assignments

**Export Problems:**
- Check file format compatibility
- Verify data range selections
- Review permission settings
- Contact support if needed
