## Expense Categories and Setup

### Creating Expense Categories

**Standard Categories:**
- **Events & Social**: Parties, mixers, formal events
- **Administrative**: Office supplies, software, communications
- **Facility**: Rent, utilities, maintenance, cleaning
- **Equipment**: Furniture, technology, chapter property
- **Charitable**: Donations, philanthropy events, community service
- **Travel**: Transportation, lodging, conference fees
- **Marketing**: Recruitment materials, advertising, promotional items
- **Food & Beverage**: Catering, groceries, dining events

**Custom Categories:**
1. **Access Category Management**
   - Go to Finance Dashboard
   - Navigate to Expenses section
   - Click "Manage Categories"

2. **Create New Category**
   - Enter category name and description
   - Set budget allocation (optional)
   - Configure approval requirements
   - Assign category managers

### Category Configuration

**Budget Limits:**
- Set spending limits per category
- Configure alert thresholds (75%, 90%, 100%)
- Enable automatic approval for small amounts
- Require additional approval for large expenses

**Approval Workflows:**
- **Under $50**: Automatic approval
- **$50-$200**: Single admin approval required
- **$200-$500**: Treasurer approval required
- **Over $500**: President and treasurer approval required

## Expense Submission Process

### For Members Submitting Expenses

**Step 1: Submit Expense Request**
1. **Access Expense Submission**
   - Go to member portal
   - Click "Submit Expense" or "Request Reimbursement"
   - Fill out expense details form

2. **Required Information**
   - Expense title and description
   - Amount and date of expense
   - Category selection
   - Receipt upload (required)
   - Business justification

**Step 2: Receipt Management**
- **Supported Formats**: PDF, JPG, PNG, HEIC
- **File Size Limit**: 10MB per receipt
- **Multiple Receipts**: Upload multiple files for single expense
- **Receipt Requirements**: Clear, legible, showing date and amount

**Step 3: Submission Review**
- Review all information for accuracy
- Confirm expense category is correct
- Verify receipt matches expense details
- Submit for approval

### For Admins Managing Expenses

**Expense Review Dashboard:**
- View all pending expenses
- Filter by category, amount, or date
- Sort by submission date or priority
- Bulk approval for multiple expenses

**Approval Process:**
1. **Review Expense Details**
   - Verify expense legitimacy
   - Check receipt authenticity
   - Confirm budget availability
   - Validate category assignment

2. **Make Approval Decision**
   - Approve: Move to payment queue
   - Request Changes: Send back with comments
   - Deny: Reject with explanation
   - Hold: Mark for further review

## Troubleshooting Common Issues

### Expense Submission Problems

**Receipt Upload Issues:**

*Symptoms:*
- File won't upload
- Receipt image unclear
- File size too large

*Solutions:*
1. Check file format (PDF, JPG, PNG only)
2. Reduce file size (under 10MB)
3. Ensure clear, legible image
4. Try different browser or device
5. Contact support if issues persist

**Approval Delays:**

*Symptoms:*
- Expenses stuck in pending status
- No response from approvers
- Approval notifications not received

*Solutions:*
1. Check approval workflow settings
2. Verify approver availability
3. Send manual approval reminders
4. Escalate to higher approval level
5. Review and update approval policies

### Budget Management Issues

**Budget Overruns:**

*Symptoms:*
- Category spending exceeds budget
- Unexpected large expenses
- Poor budget tracking

*Solutions:*
1. Implement stricter approval controls
2. Increase budget monitoring frequency
3. Set up automated alerts
4. Review and adjust budget allocations
5. Improve expense forecasting

**Reconciliation Problems:**

*Symptoms:*
- Expenses don't match bank statements
- Missing expense records
- Duplicate entries

*Solutions:*
1. Regular reconciliation procedures
2. Detailed transaction tracking
3. Proper expense categorization
4. Bank statement comparison
5. Audit trail maintenance
