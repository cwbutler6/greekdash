# Getting Started with GreekDash

Welcome to GreekDash! This guide will help you set up your chapter and get started with managing your organization effectively.

## What is GreekDash?

GreekDash is a comprehensive chapter management platform designed specifically for fraternities and sororities. It provides tools for:

- **Member Management**: Invite, approve, and manage chapter members
- **Financial Management**: Collect dues, track expenses, and manage budgets
- **Event Management**: Create events and manage RSVPs
- **Communication**: Send broadcasts and manage chapter communications
- **File Sharing**: Organize and share chapter documents

## Quick Setup Checklist

Follow these steps to get your chapter up and running:

1. **Complete Chapter Profile**
   - Add your chapter name and description
   - Upload your chapter logo
   - Set your chapter colors

2. **Configure Basic Settings**
   - Set up your chapter's public page
   - Configure privacy settings
   - Set up notification preferences

3. **Invite Your First Members**
   - Send invitations to existing members
   - Set up member roles and permissions
   - Configure approval workflows

4. **Set Up Financial Management**
   - Create dues plans
   - Connect Stripe for payment processing
   - Set up expense categories
