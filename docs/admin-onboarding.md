## Initial Setup

### First Login Checklist
After your chapter is created, complete these essential steps:

- [ ] **Upload Chapter Logo** - Add your fraternity/sorority logo and branding
- [ ] **Set Chapter Colors** - Customize your chapter's primary colors
- [ ] **Configure Contact Information** - Add chapter address, phone, and email
- [ ] **Generate Join Code** - Create a secure code for members to join
- [ ] **Set Up Dues Plans** - Configure membership dues and payment schedules
- [ ] **Send First Invitations** - Invite your initial admin team

### Accessing Admin Features
All admin features are located under `/[your-chapter]/admin/` routes. These include:
- Member management and invitations
- Financial dashboard and dues collection
- Event creation and management
- Chapter settings and branding

## Chapter Configuration

### Branding Setup
1. **Logo Upload**: Navigate to Chapter Settings → Branding
   - Recommended size: 200x200px PNG or SVG
   - Will appear on member portal and public pages

2. **Color Scheme**: Set your primary chapter colors
   - Used throughout the member portal
   - Maintains brand consistency

3. **Chapter Information**:
   - Chapter name and Greek letters
   - Contact information
   - Chapter description for public page

### Security Settings
- **Join Code Management**: Regenerate codes periodically for security
- **Admin Permissions**: Carefully manage who has admin access
- **Audit Logs**: Review all admin actions in the audit log

## Member Management

### Invitation Process
1. **Send Invitations**:
   - Go to Admin → Members → Invite New Member
   - Enter email address and select role (Member or Admin)
   - System sends secure one-time invitation link

2. **Pending Approvals**:
   - Review members who joined via join code
   - Approve or deny pending memberships
   - All actions are logged for audit purposes

3. **Member Roles**:
   - **Admin**: Full access to admin features
   - **Member**: Access to member portal only
   - **Pending**: Awaiting approval (limited access)

### Member Lifecycle Management
- **Profile Updates**: Members can update their own profiles
- **Deactivation**: Temporarily disable member access
- **Role Changes**: Promote members to admin or vice versa
- **Data Export**: Export member lists and contact information

## Financial Management

### Dues Collection
1. **Set Up Dues Plans**:
   - Navigate to Admin → Finances → Dues Plans
   - Configure amount, frequency, and due dates
   - Set up automatic reminders

2. **Payment Processing**:
   - Integrated with Stripe for secure payments
   - Members pay via credit card or bank transfer
   - Automatic receipt generation

3. **Financial Reporting**:
   - View payment history and outstanding balances
   - Export financial data to CSV
   - Track refunds and payment disputes

### Donation Management
- Set up donation campaigns
- Track donor information
- Generate tax receipts

## Events & Communication

### Event Management
1. **Create Events**:
   - Add event details, date, time, and location
   - Set RSVP requirements
   - Upload event images

2. **RSVP Tracking**:
   - Monitor attendance responses
   - Export attendee lists
   - Send event reminders

### Communication Tools
- **Announcements**: Send chapter-wide messages
- **Email Campaigns**: Targeted messaging to member segments
- **SMS Notifications**: Important updates via text (if enabled)

## Best Practices

### Security
- Use strong passwords and enable 2FA when available
- Regularly review admin access and permissions
- Monitor audit logs for suspicious activity
- Keep join codes confidential and rotate them regularly

### Member Onboarding
- Send welcome messages to new members
- Provide clear instructions for profile completion
- Set expectations for dues payment and participation

### Data Management
- Regularly backup important chapter data
- Keep member information up to date
- Respect member privacy and data protection

### Financial Best Practices
- Set clear dues policies and communicate them
- Process refunds promptly when needed
- Maintain accurate financial records
- Review subscription limits based on your plan

## Subscription Plans & Limits

### Free Plan
- Up to 10 members
- Basic features only
- Limited storage (1GB)

### Basic Plan ($29/month)
- Up to 30 members
- Full feature access
- 3GB storage
- Email support

### Pro Plan ($99/month)
- Unlimited members
- Advanced features
- 20GB storage
- Priority support
- Custom branding options
