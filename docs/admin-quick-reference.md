# Admin Quick Reference Guide

## Daily Tasks

### Check Pending Members
1. Go to Admin → Members → Pending
2. Review new join requests
3. Approve or deny with reason
4. Send welcome message to approved members

### Monitor Finances
1. Check Admin → Finances → Dashboard
2. Review recent payments
3. Follow up on overdue accounts
4. Process any refund requests

## Weekly Tasks

### Member Management
- Review member activity and engagement
- Update member roles if needed
- Check for inactive members
- Send reminders for incomplete profiles

### Event Planning
- Create upcoming events
- Review RSVP responses
- Send event reminders
- Update event details as needed

## Monthly Tasks

### Financial Review
- Export financial reports
- Reconcile payments with bank statements
- Review subscription usage vs. limits
- Plan for upcoming dues cycles

### System Maintenance
- Review audit logs for security
- Update chapter information
- Regenerate join codes
- Clean up old files and data
