# Product Overview

GreekDash is a multi-tenant SaaS platform designed for fraternity and sorority chapter management. Each chapter gets a unique slug-based subdomain with branded experiences.

## Core Features

- **Multi-tenant Architecture**: Each chapter has unique slug, branding (colors, logo), and isolated data
- **Member Management**: Directory, profiles, lineage tracking, role-based access (MEMBER, ADMIN, OWNER)
- **Financial Management**: Dues collection, expense tracking, budgets, Stripe integration, treasury DeFi features
- **Event Management**: Chapter events with RSVP system, public/private events
- **Communication**: SMS/email broadcasts, contact forms, feedback system
- **File Sharing**: Chapter document management with folder organization
- **Donations**: Campaign management with Stripe checkout integration
- **Audit Logging**: Comprehensive activity tracking for compliance

## User Roles

- **OWNER**: Full chapter control, billing management
- **ADMIN**: Chapter management, member operations
- **MEMBER**: Basic access to portal features
- **PENDING_MEMBER**: Limited access during onboarding

## Subscription Tiers

- **FREE**: Basic features with limits
- **BASIC**: Enhanced member management
- **PRO**: Full feature set including advanced finance tools
- **ENTERPRISE**: Custom solutions

The platform emphasizes ease of use, mobile responsiveness, and accessibility while maintaining security and compliance standards.
